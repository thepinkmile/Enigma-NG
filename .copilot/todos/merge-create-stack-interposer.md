## Description

Create design files for the Stack-Interposer Board — the passive PCB that connects
Stack-Output back to Stack-Input internally within each mini-stack, replacing the
original ribbon cable IDC approach.

## Notes

- Passive interposer link between Stack-Output and Stack-Input inside each mini-stack.
- Uses shrouded IDC-header family connectors (right-angle female on Stack-Input/Stack-Output).
- Improves signal shielding and makes the mini-stack assembly mechanically rigid.
