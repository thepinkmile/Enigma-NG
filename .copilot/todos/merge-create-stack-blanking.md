## Description

Create design files for the Stack-Blanking Board — the termination board fitted to the rear
of the last Rotor Mini-Stack in the chain, or used standalone with the Cypher Board.

## Notes

- Passive PCB with routed traces connecting Stack-Input back females to Stack-Output back females.
- Uses QTS-025-01-L-D-A-GP-K-TR vertical male plugs on its single face.
- Routes TTD_RETURN and ENC_DATA from rear-top-right to rear-top-left.
