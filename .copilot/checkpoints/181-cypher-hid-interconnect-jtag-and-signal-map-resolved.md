## Key architecture decisions this session

| Decision | Detail |
| --- | --- |
| 4-connector HID board architecture | Cypher-Input and Cypher-Output each carry 4 connectors instead of 1: 2 male at the top edge (mate upward), 2 female at the bottom edge (mate downward), inset from the board sides for mechanical stability. Left pair = 3V3_ENIG/GND/Plugboard passthrough (signals TBD). Right pair = shared JTAG + signal template, identical pinout regardless of which board (Input/Output) occupies which physical slot ("either order" support). |
| Connector Definition Owner moved to Cypher Board | The shared right-pair pin template is now owned by `Cypher/Board_Layout.md §4`, not by Cypher-Input. Cypher-Input/Output's own `Board_Layout.md` files reference it and define only their own per-pin wiring. |
| MPN/orientation correction | Cypher Board's own connectors (facing down to receive whichever HID board is closest) are **vertical female** `QSS-025-01-L-D-A-GP-K` — matching the existing Stack-Input/Cypher J3/J4 "hub" pattern. HID boards' top/bottom connectors are **right-angle** `QTS-025-01-L-D-RA-P` (male) / `QSS-025-01-L-D-RA-K` (female), matching the existing Stack-Input J1/J2 pattern. (Caught and corrected an initial wrong MPN/JLCPCB-PN guess during implementation — see `Cypher-Input/Design_Spec.md` BOM.) |
| Revised 37-device JTAG chain order | FT232H (U17) -> Cypher-Input CPLD (device 1) -> Cypher-Output CPLD (device 2) -> 4x Plugboard Encoder Modules (devices 3-6) -> Cypher Board's own U1 CPLD (device 7) -> 30x Rotor CPLDs (devices 8-37) -> `TTD_RETURN` -> FT232H. All "static" CPLDs precede the "dynamic" Rotor stack. U1 moved from chain position 1 to position 7. |
| `TTD` naming convention applied consistently | Per existing system convention (same as Rotor mini-stack), the JTAG serial data signal is named `TTD` at every hop, never `TDI`/`TDO`/`_FWD`/`_RET`. Superseded the old `JTAG_TDI_FWD`/`JTAG_TDO_RET`/etc. naming from the original Entry 19 draft. |
| Full 50-pin unified map (right connector pair) | `ENC_DATA[5:0]` (pins 3-14), `BOARD_ROLE_ID[2:0]` (17-22), `CPLD_RESET_N` (23, single pin), `ENC_ACTIVE_KBD_N` (24, renamed from placeholder `ENC_ACTIVE_INPUT_N`), GND bar (25/26), `I2C_SDA`/`I2C_SCL` (29/31), `GREEN_PWM_N`/`YELLOW_PWM_N` (30/32), `TTD` x3 + `TMS` + `TCK` (33-50). Row convention: top row = whichever board is documented as generating/consuming that signal in its primary role; bottom row = straight passthrough to the other HID board. |
| `BOARD_ROLE_ID[2:0]` encoding (MSB-to-LSB) | `000` = 64-Char Variant, `001` = 26-Char Variant, `010` = 10-Numeric Variant, `011`-`111` reserved for future use. Feeds the Cypher Board's I2C expander (U6) for board-variant auto-detection. |
| `ENC_ACTIVE_KBD_N` renamed and re-homed | Renamed from the draft placeholder `ENC_ACTIVE_INPUT_N` to match the Cypher Board's existing internal net name (`Design_Spec.md §3`, U6 GPA[6]). Generated by Cypher-Input, consumed by Cypher-Output (LED activation) and tapped by the Cypher Board's I2C expander (U6) for rotor-actuation triggering. |
| New `merge-create-plugboard` todo | Tracks the future termination/blanking board for the bottom of the Cypher-Input/Cypher-Output local stack — mirrors Stack-Blanking's role for the rotor mini-stack chain. Termination resistor values (10 kOhm ERJ-2RKF1002X, TCK pull-down / TMS+CPLD_RESET_N pull-up) copied from `Stack-Blanking/Design_Spec.md §3`. Added to `merge-update-top-level-docs`'s dependency list. |
